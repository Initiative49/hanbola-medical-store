# حنبولة Medical Store v5
نسخة HTML/CSS/JavaScript فقط بدون قاعدة بيانات.

التعديلات:
- إصلاح زر القائمة الثلاثي في أعلى اليمين.
- اسم المتجر والشعار أصبحا أوضح ومتوازنين داخل الهيدر.
- البانر أصبح إعلاناً أفقياً بعرض الصفحة بدلاً من صندوق صورة في منتصف البانر.
- ارتفاع البانر صغير ومناسب للهاتف.
- السلايدر يتحرك تلقائياً كل 5 ثوانٍ، يتوقف عند التفاعل، ويدعم السحب على الهاتف.
- لا توجد أسهم انتقال.
- مؤشرات صغيرة أسفل السلايدر.
- خطوات الطلب أصبحت ثلاث بطاقات أفقية بأيقونات SVG نظيفة.
- الصور الخارجية: images/001.jpg, images/002.jpg, images/003.jpg
- العملة الأساسية USD والثانوية YER بسعر 1 USD = 1,580 YER.

## آخر تعديل
- دمج قسم «لماذا حنبولة؟» داخل الفوتر أسفل اسم المتجر وعبارة الجودة وقبل حقوق التصميم والحقوق.


## v5.2
- إزالة عبارة «متجر المستلزمات الطبية» من أسفل اسم المتجر.
- وضع الشعار داخل دائرة مستقلة بين اسم المتجر والبانر، بخلفية داكنة مؤقتة وواضحة.
- منع تداخل الشعار مع البانر.
- جعل قائمة الهاتف عمودية ومنسدلة فوق المحتوى بدون دفع العناصر.
- في السلة يتم عرض الريال اليمني فقط، مع إبقاء سعر الصرف مستخدمًا داخليًا دون عرضه.
- جعل فوتر السلة مطابقًا لفوتر الصفحة الرئيسية.
- جعل صفحات السلة تمتد حتى أسفل الشاشة مع تثبيت الفوتر في نهاية الصفحة.

## v5.3
- شعار دائري صغير مدمج داخل الهيدر أسفل اسم حنبولة.
- قائمة الهاتف تعمل على جميع الصفحات.
- توحيد الهيدر والفوتر في جميع الصفحات.
