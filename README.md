# حنبولة Medical Store v4
HTML + CSS + JavaScript فقط، بدون قاعدة بيانات.

## أهم التعديلات
- قائمة الخطوط تعمل على الهاتف وتظهر في يمين الهيدر.
- اسم المتجر واللوقو الصغير أسفل الاسم متمركزان في الهيدر.
- إزالة محرك البحث من فوق البانر.
- إزالة زر "تصفح المنتجات" من وسط البانر.
- البانر أصبح Slider من 3 صور، يتغير تلقائياً كل 4 ثوانٍ مع أزرار السابق/التالي.
- صور السلايدر: `images/001.jpg`, `images/002.jpg`, `images/003.jpg`.
- العملة الأساسية USD.
- العملة الثانوية YER.
- سعر الصرف الثابت: 1 USD = 1,580 YER.
- السلة تعرض الدولار كأساسي والريال اليمني كسعر ثانوي.
- الطلب عبر WhatsApp يعرض العملتين.
- الأقسام قابلة للإضافة من `data/store-data.js`.
